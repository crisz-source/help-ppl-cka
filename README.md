# help-ppl-cka

Estudo em público para a certificação **CKA (Certified Kubernetes Administrator)**, em português do Brasil. Gratuito e open source, publicado com MkDocs Material.

Site: <https://crisz-source.github.io/help-ppl-cka/>

## Rodar localmente

```bash
pip install -r requirements.txt
mkdocs serve
```

Abra <http://127.0.0.1:8000>.

## Estrutura

- `docs/<numero-dominio>-<nome-dominio>/<topico>.md`: uma página por tópico, organizadas pelos domínios do currículo.
- `excalidraw/`: diagramas editáveis (extensão Excalidraw do VS Code).
